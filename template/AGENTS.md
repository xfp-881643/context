# Project Instructions

This project maintains its persistent knowledge in `.context/`.

## Mandatory Context Initialization

Before starting any meaningful task:

1. Read `.context/RULES.md`.
2. Read `.context/INDEX.md`.
3. Read `.context/CURRENT.md`.
4. Read relevant project, development, architecture, module, problem, and knowledge documents.
5. Check related task history before implementing changes.

## Mandatory Context Maintenance

During work:
- Preserve important discoveries and technical decisions.
- Record verified solutions and failed approaches.
- Identify knowledge that should be reused in future tasks.

After meaningful work:
- Update the task history.
- Update CURRENT.md.
- Promote reusable knowledge into the appropriate documents.
- Update INDEX.md when documents are added, removed, or significantly changed.

## Important

- All persistent project context must be stored in `.context/`.
- Follow `.context/RULES.md` for detailed procedures.
- Do not create another memory directory.
- Do not store credentials, API keys, tokens, or secrets.
- Context must remain human-readable and agent-independent.
